# GhostCard Lab — სასწავლო NFC პროექტი

ეს არის Android პროექტის წყარო, არა მზა APK. იყენებს საკუთარ AID-ს F047484F535401 და category=other-ს; არ შეიცავს Visa/Mastercard ემულაციას. ყველა თანხა სიმულირებულია. ჩვეულებრივ საბანკო ან სათამაშო აპარატს თამაშს არ ჩაურთავს.

## აწყობა

საჭიროა კომპიუტერი, JDK 17, Android Studio, Android SDK Platform 35 და Gradle 8.9. პროექტს Gradle Wrapper-ის ბინარული ფაილი არ მოჰყვება. Android Studio-ში გახსენი ეს საქაღალდე და Gradle-ის ადგილობრივ ინსტალაციად მიუთითე 8.9, Gradle JDK — 17. გაუშვი Gradle Sync. SDK-ის გზა Android Studio-მ local.properties-ში უნდა შეიტანოს.

ან JDK/SDK-ის გამართულ გარემოში, Gradle 8.9-ით:

```sh
gradle :app:assembleDebug
```

APK: app/build/outputs/apk/debug/app-debug.apk. იგივე APK დააყენე ორივე ტელეფონზე. APK-ის ინსტალაცია და ტესტი აქ არ შესრულებულა.

## Pixel 7 + მეორე Android

1. ორივეზე ჩართე NFC, განბლოკე ეკრანები და გახსენი აპი.
2. მეორე ტელეფონზე ჯერ აირჩიე წამკითხველის რეჟიმი, დააკოპირე ეკრანზე ნაჩვენები 64-სიმბოლოიანი HEX გასაღები Pixel 7-ზე და შეინახე. გასაღები პირადი სატესტო საიდუმლოა — ჟურნალში არ გამოიტანო.
3. მეორე ტელეფონზე აირჩიე „ბარათის რეჟიმი“. მისი საწყისი სასწავლო ბალანსია 10 ₾.
4. Pixel 7-ზე აირჩიე „წამკითხველის რეჟიმი“, შემდეგ „მოვამზადო 1 ₾-ის სატესტო ოპერაცია“.
5. ტელეფონების უკანა მხარეები მიადე ერთმანეთს, ნელა მოძებნე ანტენების პოზიცია და გააჩერე შედეგამდე.
6. წარმატებისას ბარათის ბალანსი გახდება 9 ₾; Pixel-ის საკუთარი ადგილობრივი ბალანსი არ იცვლება. ბარათზე დააჭირე ჟურნალის განახლებას.
7. თითო ახალ ოპერაციას Pixel-ზე ხელახლა მომზადება სჭირდება. ტელეფონების როლების გაცვლაც შეიძლება; თითოეულს საკუთარი სატესტო ბალანსი აქვს.

თუ NFC რეაქცია არ არის: მოაშორე სქელი ქეისები, ორივე ეკრანი დატოვე განბლოკილი, შეამოწმე რომ ზუსტად ერთი ტელეფონია წამკითხველი. სხვა აპის AID კონფლიქტზე პასუხი არ ივარაუდო — გადაიღე ორივე ჟურნალი.

## პროტოკოლი

- SELECT: 00 A4 04 00 07 F047484F535401 00
- გამოწვევა: 80 10 00 00 00 → 16 შემთხვევითი ბაიტი + 9000.
- ჩამოჭრა: 80 20 00 00 44 + nonce(16) + transactionID(16) + amount(4, big endian) + HMAC-SHA256(32).
- HMAC-ის ტექსტია nonce + transactionID + amount; თანხა მხოლოდ 100 სატესტო თეთრია.
- პასუხი: იგივე 36-ბაიტიანი ტექსტი + ნაშთი(4) + მრიცხველი(4) + HMAC(32) + 9000.
- 6982: MAC არასწორია; 6984: განმეორებითი ID; 6985: არასწორი სესია; 6A80: თანხა დაუშვებელია; 6A84: ბალანსი არასაკმარისია; 6581: შენახვის შეცდომა/ჟურნალი სავსეა.

თუ კავშირი ჩამოჭრის გაგზავნის შემდეგ გაწყდა, შედეგი უცნობად აღინიშნება. ხელახლა გაგზავნა ავტომატურად არ ხდება: ჯერ ბარათის ჟურნალი/ბალანსი შეამოწმე. ეს დემო განაწილებულ ატომურ ტრანზაქციებს არ ახორციელებს.

## შემოწმება
